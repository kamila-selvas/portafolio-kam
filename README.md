## Despliegue en GitHub Pages
1. Crea un repositorio público (p. ej. `portafolio`) y sube estos archivos.
2. En GitHub: Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
3. Espera 1–2 minutos: tu sitio queda en `https://TU-USUARIO.github.io/portafolio/`.
4. Pega ese enlace en tu entrega.
