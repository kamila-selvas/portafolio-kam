CAPV EDU

Sistema web para organizar asesorías académicas: los estudiantes reservan sesiones con docentes según su horario disponible y todo queda registrado en un solo lugar.

Sistema inteligente

Inclusive Elevator

Prototipo de elevador pensado para que cualquier persona lo use a su manera: se controla con la voz, con gestos frente a una cámara o con botones físicos.

Un programa en Python interpreta la voz y los gestos, y una placa Arduino mueve el prototipo según lo que el usuario indique.

Python · Arduino · MediaPipe · OpenCV · PyQt5
